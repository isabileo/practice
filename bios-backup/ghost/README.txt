SYMANTEC GHOST 11 — place YOUR licensed copy here
=================================================

This folder is empty on purpose.

Symantec Ghost 11 is proprietary commercial software. This USB kit does
NOT redistribute Ghost. Use only a copy you are licensed to use.

WHAT TO COPY HERE (from your Ghost 11 CD / licensed install)
------------------------------------------------------------
Copy the Ghost program files into this folder, for example:

  ghost\
    Ghost32.exe      ← required for Windows XP / 7 / 10
    Ghost.exe        ← optional (DOS)
    Ghost64.exe      ← optional
    *.dll / support files that came with your Ghost 11 package

Typical source: Symantec Ghost 11 Solution Suite CD, or an install
tree you already own.

AFTER YOU COPY THE FILES
------------------------
Windows XP / 7 / 10 (OS still boots):
  1. Plug in this USB
  2. Run:  ..\windows\RUN-MENU.bat
  3. Choose "Symantec Ghost 11"
  4. In Ghost:
       - Local → Disk → To Image     (backup whole disk to .GHO)
       - Save image on: this USB, another internal/external disk, or CD/DVD
       - Or Disk → To Disk           (clone to another disk in the same PC)

Boot menu (Linux live) on this USB:
  bios-menu → Disk / Drives → Symantec Ghost 11
  shows whether Ghost32.exe is present and how to run it.

WINDOWS 10 NOTE
---------------
If Ghost32.exe fails to start, right-click → Properties → Compatibility
→ "Windows XP (Service Pack 3)" → Apply, then run again.

CD / DVD BACKUPS
----------------
Ghost 11 can write images spanning CD/DVD when a burner is present.
Prefer a USB or second hard disk when possible (faster, fewer discs).
